# Buy Me a Coffee ☕️ – Web3 Edition

A modern, minimal, and secure "Buy Me a Coffee" web application built with [Vite](https://vitejs.dev/) + [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) and styled with [Tailwind CSS v4](https://tailwindcss.com/). This project leverages [RainbowKit](https://www.rainbowkit.com/) for seamless Web3 wallet integration, making it easy for users to connect their crypto wallets and support you with a coffee!

## 🚀 Features

- **Web3 Wallet Integration:** Effortlessly connect MetaMask, WalletConnect, and more using RainbowKit.
- **Fast & Modern Stack:** Powered by Vite for lightning-fast development and HMR.
- **TypeScript:** Type-safe codebase for reliability and maintainability.
- **Tailwind CSS v4:** Utility-first, responsive, and modern styling out of the box.
- **Clean UI:** Minimal, user-friendly interface focused on conversion.

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Styling:** Tailwind CSS v4
- **Web3 Integration:** RainbowKit, wagmi

## 📦 Getting Started

1. **Clone the repository:**

   ```bash
   git clone https://github.com/your-username/buy-me-a-coffee-rainbow-kit.git
   cd buy-me-a-coffee-rainbow-kit
   ```

2. **Install dependencies:**
   ```bash
   bun install
   ```
3. **Start the development server:**
   ```bash
   bun run dev
   ```
4. **Open your browser and visit `http://localhost:5173/` to see the app in action!**

## Wallet Integration

This project uses RainbowKit for wallet onboarding and management. Users can connect their favorite wallets and send you a coffee (crypto tip) with just a few clicks.
